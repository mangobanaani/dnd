# Release Notes - v0.1.0

## Initial Release

We are excited to announce the initial release of the D&D Campaign Manager! This version focuses on providing a robust, offline-first experience for Dungeon Masters and players.

### Key Features

- **Local-First Architecture**: All data is stored locally in your browser, allowing for offline use and rapid prototyping.
- **Campaign Management**: Create and manage campaigns, including NPCs, locations, quests, and sessions.
- **Character Sheet**: Comprehensive character management with auto-calculations for abilities, skills, and more.
- **Combat Tracker**: Fluid initiative tracking with drag-and-drop support.
- **Monster Compendium**: Access to over 2,400 monsters with filtering and encounter building.
- **Dice Roller**: Integrated 3D-like dice rolling experience.

### Known Issues / Limitations

- **Authentication**: User authentication is currently disabled for this local-preview release.
- **Cloud Sync**: Data is not yet synced to the cloud (Supabase integration is planned for v0.2.0).
- **PWA**: Offline installation is not yet fully enabled.

### Getting Started

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the application.
4. Open `http://localhost:3000`.

Enjoy your adventures!
